# Contributing

Bug reports and pull requests are welcome.

## Reporting a bug

Open an [issue](https://github.com/MehmetAliAtik/flowreader/issues) and describe what you did, what you expected and what happened, along with your operating system and app version.

If a particular PDF triggers the problem, please do not attach copyrighted or private documents. A small file you made yourself that reproduces it is ideal.

## Pull requests

1. Set up the project as described under [Development](README.md#development).
2. Keep each pull request focused on one change.
3. Run `npm run build` (it type-checks the code) and try your change with `npm run dev`. There is no automated test suite.
4. If you add or update a runtime dependency, update [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).

Contributions are accepted under the project's [MIT License](LICENSE). Only submit work that you have the right to license that way.
